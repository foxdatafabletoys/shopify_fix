Learnings:
- /resources/ static HTML has empty media-library__results div; tiles load
  client-side from /wp-json/gw/v2/media. The legacy scraper sees only the
  hard-coded ZIPs in static HTML.
- Cloudflare blocks bare urllib User-Agents. Browser UA + Referer header
  works for unauthenticated GETs.
- file_name format: "<SKU>_<slug>.jpg". Existing _extract_asset_match_code
  picks longest 8-14 digit run, so the SKU is matched even after
  build_flattened_filename prepends the URL parent (year/month).
- gw_country_id cookie returns 220 (UK) when fetching /resources/ as new visitor.
